⚙️ Configuração

Defina prompt, modelo e chaves. Tudo salvo no servidor.

Provedor & Modelo

    🔑 API Keys

    Uma chave por provedor. Fica salva em config.json (local).

    📝 Prompt do Sistema

    🤖 Agente Testador

    Um segundo agente conversa sozinho com a IA-alvo e gera um relatório. Deixe vazio para usar o mesmo provedor/modelo da conversa.

    🧠 Memória

    Cada conversa tem um session_id. As últimas N mensagens viram contexto — igual ao nó "Postgres Chat Memory" do n8n.

    🗄️ Banco de dados SQLite

    Vazio = usa SQLite local. Preencha para guardar a memória no seu Supabase (Postgres). A chave fica só no servidor.

    🔧 Tools

    O prompt pode "ativar" estas tools. Elas não executam nada real — o sistema só avisa quando são acionadas.
